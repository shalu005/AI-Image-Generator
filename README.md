# AI Image Generator Using Stable Diffusion

## Project Description
The AI Image Generator is a web-based application that generates images from text prompts using Stable Diffusion.

Users can enter a text description and generate realistic AI images.

## Technologies Used
- Python
- Stable Diffusion
- Google Colab
- Gradio

## Features
- Generate images from text prompts.
- Adjust inference steps.
- Change guidance scale.
- Set random seed values.
- View and download generated images.

## How to Run
1. Open the AI_image_generator.ipynb notebook in Google Colab.
2. Run all the code cells.
3. Enter your desired text prompt.
4. Adjust the generation settings.
5. Click Submit to generate an image.
6. Download the generated image.

## Project Output
The application generates AI images based on the user's text prompts.
